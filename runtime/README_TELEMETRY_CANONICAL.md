# CANONICAL TELEMETRY LOCATION

The following paths are the canonical runtime telemetry surfaces:

- runtime/logs/
- runtime/telemetry/append_only/

These locations contain:
- governance telemetry
- append-only runtime evidence
- escalation telemetry
- replay-capable governance events
- immutable audit chains

Non-canonical telemetry locations should be treated as:
- exports
- snapshots
- legacy compatibility layers
- historical evidence copies

Canonical runtime telemetry ownership:
HHI_GOV_01/runtime/
